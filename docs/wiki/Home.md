## 2026-11-16 · 좌표계 내적 변환과 Point3D 구현

로컬 축 ex=(0,1,0), ey=(-1,0,0)을 직접 표현했고, ez=(0,0,0)은 (0,0,1)로 교정했다. Z가 0이 아닌 좌표의 양방향 손계산, ex·ey=0과 |ex|=1, 비단위축에서 내적만으로 원래 계수가 나오지 않는 사례를 확인했다.

Point3D와 Coordinate 콘솔을 작성해 world-origin=(-4,6,2), 로컬 좌표 (6,4,2)를 학습자가 직접 실행했다. 코드 검토에서 ToVector의 Z 누락을 찾아 학습자가 Vector3D(X,Y,Z)로 수정했고 소스로 확인했다. 문서 갱신 시 도구로도 Coordinate를 다시 빌드·실행해 같은 두 출력을 확인했다. [입력·답변·교정·검증 범위](Study-2026-11-16.md)

P1-12는 진행 중이며 기존 완료 수는 유지한다. C# 정방향·왕복 오차·일반 축 검증과 새 OCCT 실행은 아직 하지 않았다.

**다음:** 로컬 (6,4,2)를 월드 (1,4,3)으로 복원하는 ToWorld를 구현하고, ToLocal과 함께 함수로 정리해 왕복 오차를 확인한다. 이후 일반적인 정규직교 축과 잘못된 축 입력을 검증한다.

## 2026-11-17 · 좌표계 클래스와 왕복 검증 완료

ToWorld/ToLocal을 구현하고 정수 축 오차 0, 소수 축 오차 8.8817841970012523E-16, 일반적인 3D 축의 로컬→월드→로컬 오차 1.2560739669470201E-15를 학습자가 직접 실행해 확인했다. 모두 거리 허용오차 1e-10 이내다. 비단위축 반례와 비직교축 거부, IsOrthonormal, 생성자 검증 및 읽기 전용 속성을 가진 CoordinateSystem3D를 학습했다. [실제 결과·코드·검증 범위](Study-2026-11-17.md)
