# Phase 5 · Nesting Engineering

[Home](Home.md) · [이전 Phase](Phase-4-Optimization.md) · [다음 Phase](Phase-6-AI-Geometry.md)

**목표:** 기하 판정과 최적화를 결합한 작은 2D Nesting 엔진을 구현한다. **참고 기간:** 8~12주. **상태:** 전 항목 미착수.

## 범위와 수학적 모델

고정 폭 W의 원단에서 모든 패턴을 배치하고 사용 길이 L을 최소화하는 strip packing으로 시작한다. 패턴 i의 위치는 (xi, yi), 회전은 허용 집합 Θi에서 선택한다. 단순 다각형 5~10개와 명시적인 허용 회전으로 시작하고 홀·곡선·대량 패턴은 나중으로 미룬다.

제약은 원단 내부, 패턴 간 겹침 금지, 허용 회전 준수다. 의류 패턴의 결 방향·앞뒤·좌우 대칭 허용 여부와 재단 간격을 별도로 정의한다. 반사를 회전과 동일하게 취급하지 않는다. 간격 기능은 먼저 0으로 시작하고 Offset 검증 후 도입한다.

## 세부 학습 순서

아래 단계는 여러 회차로 나뉘며 회차당 30~60분을 지킨다.

| 순서 | 작은 기능 | 완료 기준 |
|---|---|---|
| 1 모델링 | 입력 도형·원단 폭·목적 함수 정의 | 유효/무효 배치 사례를 수작업으로 분류 |
| 2 패턴 회전·이동 | 로컬 꼭짓점→배치 좌표 | 거리·면적 보존과 회전 중심 검증 |
| 3 Bounding Box | 각 배치의 AABB 계산 | 변환 뒤 꼭짓점을 모두 포함 |
| 4 Polygon 교차 | Phase 2 판정 재사용 | 변 교차·완전 포함·접촉 정책 검증 |
| 5 배치 가능 여부 | 원단 경계+충돌+회전 제약 | invalid 해를 최종 출력에서 제외 |
| 6 후보 생성 | 작은 격자 또는 꼭짓점 기반 후보 | 후보를 재현 가능하게 생성하고 누락 한계 설명 |
| 7 점수 계산 | 가능한 해의 L, 동점 규칙 | 손계산 점수와 일치 |
| 8 Greedy Nesting | 면적 순서+후보 점수 기반 자동 배치 | 합성 패턴 전체 배치 또는 실패를 명시 |
| 9 Local Search/SA | 순서·회전 이웃, 디코딩 후 재판정 | baseline 대비 개선 여부와 비용 기록 |
| 10 시각화·평가 | 결과 SVG 또는 간단한 뷰어, CSV | 겹침 없이 보이는 것과 수치 판정이 함께 일치 |

## Mini Nesting 검증

사용률은 `Σ 원본 패턴 면적 / (W × 실제 사용 길이 L)`로 계산한다. L>0이며 모든 패턴이 경계 안에 있고 겹치지 않아야 의미가 있다. 고정 길이 원단으로 바꾸면 분모와 목적 함수도 바뀐다고 명시한다. 간격을 위해 팽창시킨 도형의 면적은 원본 패턴 면적과 분리한다.

대칭 사각형, 오목 도형, 가늘고 긴 도형, 완전 포함, 경계 접촉, 회전 제한 사례를 둔다. 같은 데이터·seed·시간 예산으로 Greedy와 개선 탐색을 비교한다. 먼저 가능한 해를 만든 뒤 품질을 개선한다.

NFP(No-Fit Polygon)는 기본 엔진 이후 선택 심화다. 후보 생성과 충돌 검사 비용을 줄일 필요가 실제로 확인되면 도입하며, Minkowski sum·홀·퇴화 처리를 작은 단계로 나눈다.
