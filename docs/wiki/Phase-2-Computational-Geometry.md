# Phase 2 · Computational Geometry

[Home](Home.md) · [이전 Phase](Phase-1-3D-Math.md) · [다음 Phase](Phase-3-OpenCascade.md)

**목표:** 패턴 CAD의 측정·스냅·교차·영역 판정에 필요한 알고리즘을 직접 구현한다. **참고 기간:** 10~12주. **상태:** 미착수.

선행 조건은 벡터·내적·2D 방향 판정·변환 이해다. 기존 Point2D/Vector2D를 재사용한다. 복잡한 다각형 연산을 한 회차 안에 완성하려 하지 않는다.

## 세부 순서·실습·완료 기준

각 행은 한 주차가 아니라 주제다. 구현과 경계 조건 테스트를 30~60분 단위로 나눈다.

| 순서 | 개념 | 작은 실습과 완료 기준 |
|---|---|---|
| 1 Point | 점, 좌표 단위, 동일점 허용오차 | 기존 Point2D 거리 검증; 단위와 비교 정책 설명 |
| 2 Line | 무한 직선, 매개식 p=a+td | 점·방향으로 직선 표현; 방향 0을 거부 |
| 3 Line Segment | t∈[0,1], 끝점 | 선분 생성·길이; 길이 0 처리 정의 |
| 4 Distance | 점−점, 점−선분 거리 | 내부·끝점·영길이 선분의 거리 확인 |
| 5 Projection | 내적, 투영, 매개변수 clamp | t=((p−a)·(b−a))/|b−a|²; 선분이면 [0,1]로 제한. 영분모 별도 처리 |
| 6 Intersection | orientation, 평행·수직, 교차 | 두 선분의 일반 교차→끝점 접촉→공선 겹침을 각각 테스트 |
| 7 Polygon | 꼭짓점 순서, 부호 있는 면적 | 신발끈 공식; 순서를 뒤집으면 부호 반전 |
| 8 Point in Polygon | ray casting 또는 winding | 내부/외부/경계 3상태 반환; 꼭짓점 통과 중복 집계 방지 |
| 9 Bounding Box | AABB, min/max | 다각형 AABB 생성; 회전 후 꼭짓점으로 재계산 |
| 10 Collision Detection | broad phase / narrow phase | AABB는 후보 판정, 선분 교차+포함 판정으로 실제 충돌 확인 |
| 11 Polygon Intersection | 교차 영역, 오목 다각형, 홀 | 볼록 클리핑→반례→일반 라이브러리 비교 순으로 분리 |
| 12 Convex Hull | orientation, 정렬 | monotone chain 구현; 중복점·공선점 정책과 O(n log n) 설명 |
| 13 Polygon Offset | 평행 이동 선, join, 자기 교차 | 사각형→볼록 도형→오목 반례→Clipper2 비교로 분할 |

## GeometryLab 실습 운영

코드 예정 폴더: `02-Computational-Geometry/`. 거리, 선분 교차, 다각형 판정 등 알고리즘별 작은 예제와 입력 데이터를 둔다. 같은 코드를 폴더마다 복사하지 않고 공통 타입을 참조한다.

예를 들어 선분 거리 학습은 ① 정상 투영 ② 선분 밖 clamp ③ 영길이·경계 테스트 ④ 클릭 위치에서 패턴 윤곽으로 스냅하는 예제로 나눈다. 각 단계는 30~60분이며 결과를 독립적으로 확인할 수 있어야 한다.

## 안정성과 검증

- orientation의 부호는 단순히 모든 값에 같은 epsilon을 적용한다고 안정해지지 않는다. 거의 공선인 입력, 큰 좌표·작은 간격을 별도 시험한다.
- 선분 교차는 `없음 / 한 점 / 겹치는 선분`을 구분한다. bool만으로 정보를 잃는 경우를 설명한다.
- 교차하는 변이 없어도 한 다각형이 다른 다각형 안에 있으면 겹친다. 꼭짓점 접촉·공유 변을 충돌로 볼지는 업무 규칙으로 정한다.
- 학습용 단순 구현의 지원 범위(볼록/단순 다각형, 홀 지원 여부)를 명시한다. 일반 Polygon Offset와 교집합은 다회차 심화 주제다.
- 번역·회전 후 거리/교차 판정이 보존되는지, 면적이 순서 반전에서 어떻게 변하는지 불변량 테스트를 추가한다.

- [ ] 표의 각 알고리즘을 C#으로 구현하거나, 일반화 범위를 제한한 구현과 검증된 라이브러리 비교를 남김
- [ ] 정상·경계·퇴화 입력과 정확성 한계를 기록함
- [ ] 시간 복잡도를 설명함: 예를 들어 단순 다각형 점 판정 O(n), 변 쌍 검사 O(nm)
- [ ] 거리→스냅, 교차→충돌, Offset→간격 확보로 CAD 기능과 연결함

진행 항목은 모두 미착수다. 참고 자료는 [자료 목록](References.md)의 **Clipper2**, **Shewchuk robust predicates**이며, 한국어 수학 보강은 KOCW를 사용한다. 이 단계에서 OpenCascade 적용은 선택이다.
