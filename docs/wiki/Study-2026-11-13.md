## 원점만 다른 좌표계

로컬 원점의 월드 위치 O=(10,0,0), 두 좌표계의 축 방향과 단위가 같은 조건이다.

| 문제 | 학습자 답변 | 확인 |
|---|---|---|
| 로컬 (3,2,0) → 월드 | (13,2,0) | 정답. 원점 위치를 더함 |
| 월드 (15,4,0) → 로컬 | (5,4,0) | 정답. 원점 위치를 뺌 |

## 축 방향이 다른 좌표계

원점은 O=(10,0,0)으로 유지한다. 로컬 축은 월드 +Z축 기준 +90° 방향으로 놓여 있다. 로컬 +X는 월드 +Y, 로컬 +Y는 월드 −X를 향한다. 그림은 월드 +X가 오른쪽, 월드 +Y가 위쪽인 XY 평면이며 모든 문제에서 Z=0이었다.

| 문제 | 학습자 답변·과정 | 확인 |
|---|---|---|
| 로컬 (2,0,0) → 월드 | (4,0,0) 답변 후 피드백 전에 (10,2,0)으로 수정 | 최종 정답 |
| 로컬 (0,3,0) → 월드 | (−10,3,0) | (7,0,0)으로 교정. 로컬 원점에서 월드 −X로 3이라는 그림을 보고 이해 확인 |
| 로컬 (2,3,0) → 월드 | (7,2,0) | 방향 힌트가 주어진 손계산 정답 |
| 월드 (6,3,0) → 로컬 | (7,6,0) | 원점 차 (−4,3,0)을 로컬 축 성분으로 읽어 (3,4,0)임을 단계별로 설명 |
| 그림에서 왼쪽 4의 로컬 방향 | “Y로 +방향” | 로컬 +Y 방향을 직접 확인 |
| 로컬 원점 기준 그림의 왼쪽 2·위쪽 5 → 로컬 | (5,2,0) | 정답 |
| 로컬 (5,2,0) → 월드 | 기준에 대한 질문 후 (8,5,0)을 설명으로 제시 | 학습자 독립 정답으로 집계하지 않음 |
| 로컬 (3,1,0) → 월드 | (9,3,0) | 축 대응을 명시한 문제에서 정답 |
| 월드 (8,4,0) → 로컬 | (4,2,0) | 원점 차 (−2,4,0)와 축 대응 힌트를 제공한 뒤 정답 |

## 설명 방식과 이해 확인

- “그곳”, “이 좌표계”, “왼쪽·위쪽”만으로 설명하면 월드와 로컬의 기준이 섞여 혼동했다. 이후에는 원점이 어느 좌표계로 표현되었는지, 로컬 축이 어느 월드 방향을 향하는지 명시한다.
- 좌표는 항상 (X,Y,Z) 순서다. 위 예제에서는 월드 +Y 성분이 로컬 X 성분, 월드 −X 방향 성분이 로컬 Y 성분이 된다.
- 같은 점을 다른 원점·축으로 표현하는 좌표 변환과 점 자체를 실제로 이동하는 작업을 구분해 설명했고, 학습자가 이해를 확인했다.
- 정답·교정 후 이해 확인·힌트가 있는 풀이·설명으로 제시한 결과를 구분한다. 모든 변환을 독립적으로 숙달했다고 기록하지 않는다.

## 일반식 도입

`Pw = O + x ex + y ey + z ez`

O는 로컬 원점의 월드 위치, ex/ey/ez는 로컬 각 축의 단위 방향을 월드 좌표로 표현한 벡터, (x,y,z)는 점의 로컬 좌표라고 설명했다. 학습자는 이해했다고 답했다. 단위축을 직접 작성하거나 직교성을 검증하고 일반식에 독립적으로 대입하는 과제는 아직 하지 않았다.

마지막 역변환 답변 뒤 `(10,0,0)+4(0,1,0)+2(−1,0,0)=(8,4,0)`의 복원 계산은 설명자가 제시했다. 학습자의 C# 왕복 실행이나 수치 오차 검증으로 집계하지 않는다.

## 다음 재개 지점

1. 기존 축 대응을 단위벡터로 직접 표현한다: 로컬 +X는 월드 +Y, 로컬 +Y는 월드 −X, 로컬 +Z는 월드 +Z이다. ex, ey, ez를 각각 월드 성분으로 쓰는 질문부터 시작한다.
2. O=(10,0,0), 로컬 좌표 (3,1,0)을 `Pw=O+x ex+y ey+z ez`에 직접 대입한다. 이후 Z가 0이 아닌 예제로 확장한다.
3. 각 축의 길이가 1이고 서로 내적이 0인지 확인한다. 그 뒤 C# 정방향·역방향 변환과 왕복 오차 검증으로 진행한다.

설명할 때는 “로컬 +X로 3 = 월드 +Y로 3”처럼 두 기준을 함께 표시하고, 그림의 방향만으로 문제를 내지 않는다.
