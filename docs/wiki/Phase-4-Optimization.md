# Phase 4 · Optimization Algorithms

[Home](Home.md) · [이전 Phase](Phase-3-OpenCascade.md) · [다음 Phase](Phase-5-Nesting.md)

**목표:** 배치 문제를 목적 함수·제약·탐색 공간으로 정의하고 알고리즘별 실행 시간과 해 품질을 비교한다. **참고 기간:** 8~10주. **상태:** 전 항목 미착수.

## 공통 실험 문제

합성 직사각형 4~8개, 고정 폭 원단, 이산 배치 후보와 허용 회전 집합으로 시작한다. 아주 작은 입력은 완전 탐색으로 최적값을 구하고 나머지 알고리즘의 기준으로 삼는다. 큰 입력의 최적값은 알 수 없다고 기록한다.

해는 패턴 순서·허용 회전·배치 후보로 표현한다. 겹침과 원단 밖 배치는 불가능한 해로 취급하고, 가능한 해에서는 사용 길이를 최소화한다. 제한 시간 내 미배치가 남는 경우 완전 배치 성공률을 별도로 보고한다.

## 세부 학습 순서

각 단계의 설계·구현·테스트·비교는 별도 30~60분 회차로 진행한다.

| 순서 | 개념과 실습 | 완료 기준 |
|---|---|---|
| 1 Optimization Basics | 목적 함수, 제약, 탐색 공간, 최적해/근사해 정의 | 해 3개의 가능 여부와 점수를 손계산 |
| 2 Brute Force | 작은 입력의 모든 순서/후보 탐색 | 후보 수와 실행 시간 기록, 작은 문제의 기준해 확보 |
| 3 Greedy | 면적 큰 순서 + 가장 낮은 배치 우선 등 규칙 | 결정 규칙 명시, 실패 반례 하나 설명 |
| 4 Heuristic | 순서·후보 생성 규칙을 문제 특성에 맞게 변경 | Greedy 대비 개선 또는 악화 근거 기록 |
| 5 Local Search | swap, 순서 이동, 회전 변경 이웃 | 점수가 나빠지지 않는 탐색과 정지 조건 구현 |
| 6 Simulated Annealing | 온도, 수용 확률, 냉각 | 최소화에서 악화 Δ>0를 exp(−Δ/T)로 수용; T>0 정책 확인 |
| 7 Genetic Algorithm | 염색체, 선택, 교차, 변이 | 순열 중복 없는 연산 또는 복구, 유효한 해 보존 |
| 8 Particle Swarm Optimization | 입자, 속도, 개인/전체 최선 | 연속 PSO와 이산 배치 차이 설명; random-key 등 인코딩을 명시한 작은 실험 |
| 9 성능 비교 | 시간·품질·안정성 | 동일 데이터/예산/환경에서 표와 결과 파일 작성 |

Greedy·Local Search·SA를 먼저 충분히 구현한다. GA·PSO도 작은 비교 실험까지 수행하되, 상세 튜닝은 이점이 있을 때만 확장한다. PSO를 순열 문제에 그대로 대입하지 않는다.

## 공정한 비교

데이터셋, 허용 회전, 충돌 판정, 목적 함수, 종료 기준을 동일하게 둔다. 시간 예산과 평가 횟수 모두 기록하며 주요 비교 기준을 하나 정한다. 난수 알고리즘은 고정된 여러 seed(예: 10개)로 반복하고 최선·중앙값·변동·실패율을 남긴다. 도형/후보 평가 비용까지 포함한 시간을 측정한다.
