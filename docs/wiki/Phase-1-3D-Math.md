**목표:** 3D 공간과 CAD 변환을 수학으로 설명하고 계산 결과를 형상에서 검증한다. **참고 기간:** 8~10주. **상태:** 진행 중.

## 학습 순서와 완료 기준

| 주제 | 핵심 개념 | 작은 실습(각 30~60분) | 완료 기준 |
|---|---|---|---|
| Point와 Vector | 위치와 변위, X/Y/Z, 점−점=벡터 | 기존 Point2D·Vector2D 연산 4개 검증 | 위치·변위·방향을 예제로 구분 |
| Vector 기초 | 덧셈·뺄셈, 크기, 방향, 정규화 | 기존 2D 구현 검증 후 Point3/Vector3를 회차별 구현 | 길이와 단위벡터 검증, 영벡터 정책 설명 |
| 이동 원리 복습 | p'=p+t, 벡터는 평행 이동에 불변 | 완료한 형상 이동 코드에 입력·출력 기록 | gp_Pnt/gp_Vec/gp_Dir 역할과 gp_Trsf 설명 |
| 회전 | 회전축, 오른손 규칙, 라디안, 회전 중심 | 원점 Z축 → 임의 위치 Z축 → 일반 축으로 분할 | 축 위 점 불변·거리 보존·역회전 확인 |
| 변환 합성 | Translation, Rotation, Scale, 순서 | R(T(p))와 T(R(p)) 계산 후 형상 비교 | 다른 결과의 원인을 좌표로 설명 |
| Dot Product | 투영, cosθ, 두 벡터 사이 각 | 0°/90°/180°와 영벡터 예외 검증 | clamp 필요성과 각도 정의역 설명 |
| Cross Product | 수직 방향, 오른손 방향, 평행 퇴화 | 3D 외적 구현, 평행/역순 검증 | 양쪽 입력과 수직이고 역순 부호 반전 |
| Coordinate System | World/Local, 원점·기저축, 좌표계 관계 | 직교 단위축으로 좌표계 생성 → 로컬→월드 → 역변환 | 왕복 오차를 확인하고 형상 이동과 좌표 표현 변경 구분 |
| Matrix | 행렬 연산, 회전 행렬, 동차좌표, 4×4 | 곱셈 → 점·벡터 적용 → gp_Trsf 비교를 회차별 수행 | 점 w=1, 방향 w=0과 합성 순서 설명 |
| Transformation 확장 | 스케일, 기준 좌표계, 임의 축 | 중심 기준 스케일, 로컬축과 월드축 회전 비교 | 회전은 길이 보존, 스케일은 길이 변화 확인 |

학습자가 이미 이동을 해 보았으므로 회전·합성을 작은 수치 예제로 먼저 경험하고, 이후 행렬로 일반화한다. 변환을 완전히 이해하려면 Matrix 단계를 생략하지 않는다. Vector3는 클래스 또는 값 타입 중 기존 코드 스타일에 맞춰 구현한다.

## 수학과 구현 규약

- 문서의 식은 열벡터 기준으로 `p'=M p`, `T R p`는 회전 후 이동이다. 사용 라이브러리의 행/열벡터 규약을 확인한다.
- 회전은 `θrad=θdeg×π/180`. 임의 축은 위치와 단위 방향으로 정의한다.
- 좌표계의 기저가 직교 단위축일 때 회전 역행렬은 전치행렬이다. 일반 행렬에는 무조건 적용하지 않는다.
- gp_Trsf의 지원 변환과 일반 4×4 행렬의 표현 범위는 동일하지 않다. 비균일 스케일·전단은 별도 검토 주제로 둔다.
- 길이 오차와 각도 오차를 구분하고 좌표 단위·모델 크기와 함께 기록한다.
