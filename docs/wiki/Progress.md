## 체크 방법

1. 학습을 시작하면 해당 항목의 **미착수**를 **진행 중**으로 바꾼다. 체크박스는 비워 둔다.
2. 항목에 적힌 설명·구현·검증을 직접 충족했을 때 `- [ ]`를 `- [x]`로 바꾸고 상태를 **완료**로 바꾼다.
3. 아래 학습 기록에 날짜, 항목 ID, 실제 결과와 코드/실습 링크를 남긴다.
4. 대시보드의 완료 수·진행 중 수·비율을 다시 계산하고 Home의 현재/다음 주제를 갱신한다.

**Wiki 상단 Edit에서 Markdown을 수정한 뒤 Save page로 저장한다.** 이 문서는 정적 체크리스트이므로 대시보드 숫자가 자동 갱신되지는 않는다. 완료한 항목 ID와 결과를 알려주면 체크리스트와 숫자를 함께 갱신할 수 있다.

코드가 있다는 사실, AI가 예제를 실행했다는 사실만으로 학습 완료 처리하지 않는다. 기존 구현은 다시 작성하는 대신 짧게 설명하고 테스트한다. 아래 체크리스트가 항목별 상태의 기준이며, Phase/실습 페이지의 완료 기준은 통과 조건으로 참조한다.
