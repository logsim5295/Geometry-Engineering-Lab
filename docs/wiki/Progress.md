## 체크 방법

1. 학습을 시작하면 해당 항목의 **미착수**를 **진행 중**으로 바꾼다. 체크박스는 비워 둔다.
2. 항목에 적힌 설명·구현·검증을 직접 충족했을 때 `- [ ]`를 `- [x]`로 바꾸고 상태를 **완료**로 바꾼다.
3. 아래 학습 기록에 날짜, 항목 ID, 실제 결과와 코드/실습 링크를 남긴다.
4. 대시보드의 완료 수·진행 중 수·비율을 다시 계산하고 Home의 현재/다음 주제를 갱신한다.

**Wiki 상단 Edit에서 Markdown을 수정한 뒤 Save page로 저장한다.** 이 문서는 정적 체크리스트이므로 대시보드 숫자가 자동 갱신되지는 않는다. 완료한 항목 ID와 결과를 알려주면 체크리스트와 숫자를 함께 갱신할 수 있다.

코드가 있다는 사실, AI가 예제를 실행했다는 사실만으로 학습 완료 처리하지 않는다. 기존 구현은 다시 작성하는 대신 짧게 설명하고 테스트한다. 아래 체크리스트가 항목별 상태의 기준이며, Phase/실습 페이지의 완료 기준은 통과 조건으로 참조한다.

### 이번 회차의 실제 답변과 교정

- 지정 거리 이동: P=(1,2,0), Q=(4,6,0) 방향으로 2.5만큼 이동하는 벡터 (1.5,2,0), 도착점 (2.5,4,0)을 직접 답했다.
- 정규화: 길이가 0인 벡터의 정규화 결과가 0이라는 초기 오해를 교정했다. 수학적으로 단위 방향은 없으며, 기존 코드의 영벡터 반환은 API 정책이다. 이를 성공한 정규화나 단위 방향으로 해석하지 않는다.
- 평행이동: 중심 (1,2,3)에 (-3,4,2)를 더해 (-2,6,5), 복원은 해당 이동량을 빼는 것으로 답했다. 상대 위치 계산의 Y 부호 오류는 피드백으로 교정했다.
- 원점 +Z축 회전: +90°에서 (0,4,0)→(-4,0,0), (2,3,1)→(-3,2,1), -90°에서 (2,3,1)→(3,-2,1), 180°에서 (-2,-3,1)을 직접 답했다.
- 임의 위치 축: 기준점 빼기 누락과 회전 전 Y 성분을 남기는 오류를 교정한 뒤, C=(10,0,0), P=(13,2,0)의 상대 위치 (3,2,0), 회전 (-2,3,0), 최종 (8,3,0)을 단계별로 답했다. 축 위 (10,0,5)는 불변이라고 답했다.
- 변환 순서: P=(1,0,0), t=(10,0,0), 원점 +Z축 +90°에서 이동→회전의 (0,10,0) 답을 (0,11,0)으로 교정했다. 회전→이동은 (10,1,0) 정답. 역회전→역이동은 (11,0,0)→(1,0,0), 역이동→역회전은 (0,1,0)→(1,0,0)을 직접 답했다.

다음 대화는 a=(1,0,0)에 대해 b=(1,0,0), (-1,0,0), (0,3,0)의 내적을 구하는 세 문제부터 재개한다. 이번 기록은 P1-01~10의 공통 범위에만 적용하며, 일반 방향 축 회전·외적·좌표계·행렬·Phase 2~6을 완료 처리하지 않는다.
