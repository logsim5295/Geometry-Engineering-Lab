# 실습 기록 양식

[Home](Home.md)

새 실습 페이지를 만들 때 복사한다. 복잡한 주제는 작은 실습 페이지 또는 여러 회차로 나누고 현재 흐름과 연결 이유를 적는다.

## 학습 주제

- 주제 / 연결된 Phase:
- 선행 개념 / 현재 CAD 문제와의 연결:
- 상태: 미착수 / 진행 중 / 완료
- 시간: 30~60분, 필요한 회차 수:

## 해결하려는 문제

입력, 출력, 지원 범위, 이번에 다루지 않는 조건을 정의한다.

## 핵심 수학 개념

수식, 좌표계, 단위, 각도 규약, 수치 허용오차와 그 이유를 적는다.

## 구현 방법

코드 폴더, 핵심 함수, 자료 구조, 시간 복잡도, 실행 명령을 적는다.

## C# 예제

실행 가능한 작은 호출 예제와 필요한 프로젝트 참조를 적는다. 개념 코드이면 실행 예제와 구분한다.

## OpenCascade 적용 여부

적용 / 미적용과 이유. 적용 시 OCCT·래퍼 버전, 대응 API, 검증 방법을 적는다.

## 테스트 방법

정상 입력, 경계, 퇴화 입력, 불변량, 허용오차를 정한다.

## 예상 결과

실행 전에 손계산하거나 독립 방법으로 얻은 기대값을 적는다.

## 실습 결과

미실행이면 미실행으로 남긴다. 실행 날짜, 입력, 실제값, 오차, 통과/실패, 코드 커밋, 이미지와 로그를 기록한다.

## 새롭게 이해한 점

개념을 자신의 언어로 설명하고 해결되지 않은 질문을 적는다.
