# Geometry Engineering Lab

C#과 OpenCascade로 수학·계산 기하·CAD 커널·최적화를 직접 구현하고 검증하는 학습 저장소입니다.

**[학습 Wiki Home](docs/wiki/Home.md)** · [학습 진행도·체크리스트](docs/wiki/Progress.md) · [다음 4주 계획](docs/wiki/Next-4-Weeks.md)

현재는 **Phase 1 · 3D Math**를 학습 중입니다. 2026-11-06까지 2D·3D 외적 구현, 수직성, 삼각형 넓이와 평행 입력의 넓이 0을 직접 실행해 확인했습니다. 다음은 [실습 04](docs/wiki/Lab-04-Dot-and-Cross.md)의 단위 법선 구현·정상값·평행 입력 예외 검증입니다. P1-11은 진행 중이며, 3D 역순·반평행 출력 및 거의 평행한 입력의 보완 사항은 [진행도](docs/wiki/Progress.md)에 기록했습니다.

기존 `01-3D-Math` 코드와 `3D-Engineering-Study.slnx` 구조를 유지합니다. 나머지 Phase 폴더는 해당 학습을 시작할 때 추가합니다.

2026-10-26에 [GitHub Wiki](https://github.com/logsim5295/Geometry-Engineering-Lab/wiki)에 커리큘럼을 게시했습니다. `docs/wiki`는 저장소에서 관리하는 Markdown 사본입니다. Wiki에서는 페이지 주소에 맞게 내부 링크의 `.md` 확장자를 제외했습니다. 문서를 수정할 때 저장소 사본과 Wiki를 함께 갱신합니다.
